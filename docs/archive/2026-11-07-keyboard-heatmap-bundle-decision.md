# 键盘热力图的体积预算

数据页新增键盘热力图，展示选定布局下每个键的击键强度、高频按键、高频组合键和按键分区占比。面板只在「记录键盘活动」开启时出现，几何表作为第二层按需加载模块。

## 同环境测量

对照构建使用 `0009a11` 的前端源码，与候选版本共用同一份 Node 24.22.1、Vite 8.2.4、依赖锁定和生产构建参数，仅在 `dist` 后按预算脚本的 Node gzip 口径计量。两个工作区都在 Linux 下用同一份 `node_modules` 构建，产物 gzip 与 Windows 主机构建相差在 0.03 KiB 以内。

| KiB gzip | 对照 | 接入后 | 增量 |
| --- | ---: | ---: | ---: |
| 全部 JS/CSS | 405.14 | 413.36 | +8.22 |
| Data 页面 | 22.01 | 22.88 | +0.87 |
| 键盘热力图按需模块 | — | 4.46 | +4.46 |
| 简体中文消息块 | 9.22 | 9.74 | +0.52 |
| 英文消息块 | 8.89 | 9.34 | +0.45 |
| 西班牙文消息块 | 9.97 | 10.45 | +0.49 |
| 俄文消息块 | 11.87 | 12.45 | +0.58 |
| 入口 CSS | 31.06 | 31.49 | +0.43 |
| 本地化运行时 | 7.36 | 7.56 | +0.20 |

总量增加 8.22 KiB（2.03%）。其中几何表 3.28 KiB、四种语言文案合计 2.04 KiB、面板与样式约 1.9 KiB。以上数据测量传输体积，未推算启动耗时和解析耗时。

## 成本归属

`keyboardLayout.ts` 是 400 个 ANSI 键位的纯坐标表，覆盖 60%、75%、TKL、全尺寸和笔记本五种布局；它只被热力图画布消费，因此随面板一起放进 `KeyboardHeatmapSection` 这个第二层按需模块，Data 页面首次渲染不为它付费。未开启键盘记录时该模块不会被请求。

面板本身留在 Data 页面分块内：它需要趋势面板的同一份时间范围选择，抽到按需模块会让每次进入数据页多一次模块请求，且无法减少总产物成本。

四种语言的文案各增约 0.5 KiB，包括分区名、布局名、四态提示和一条无障碍标签。键帽铭文（`A`、`Shift`、`F1` 等）不翻译，按物理键面印刷处理，登记在 `scripts/i18n/hardcoded-exceptions.ts`。

尝试过的三种压缩都被实测否定：由键名派生铭文使 raw 减少 3.4 KiB 但 gzip 反而增加 0.28 KiB；把坐标改写成紧凑数组或字符串可把几何表压到 1.15 KiB，但会牺牲可读性且需额外的解析与类型层；合并 75% 与 TKL 不可行，两者 87 键中功能键区水平偏移 25 单位。

## 预算决定

经维护者确认，总预算由 417.7 调至 426.2 KiB，增加 8.5 KiB（2.03%），保留 3% 预留后有效上限为 413.414 KiB。Data 页面预算由 22.8 调至 23.6 KiB，本地化运行时预算由 7.65 调至 7.8 KiB。其余页面、入口、公共模块、CSS 与语言块继续采用各自现有上限。
